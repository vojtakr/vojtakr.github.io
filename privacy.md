# Privacy policy

This app (Openclaw / Hermes personal assistant) is a private tool operated by and for its owner only. It is not offered to the public.

Data accessed: with the owner's consent, the app reads the owner's own Gmail messages (gmail.readonly) and can create email drafts (gmail.compose). It does not send email on its own; the owner reviews and sends drafts manually.

Use and storage: email data is processed only to give the owner summaries, reminders and draft replies. OAuth tokens and data stay on the owner's own computer. Data is not sold, shared with third parties, or used for advertising. Message content may be passed to the AI model provider the owner uses, solely to produce the answers requested.

Revoking access: access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy: the app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
